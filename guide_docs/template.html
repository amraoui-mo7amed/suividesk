Guide Pratique : Exportation & Restauration de la Base de Données
Procédure officielle pas à pas pour la sauvegarde, l'archivage et le transfert des données SuiviDesk
1 Fonctionnement de la Base de Données Locale SQLite

L'application SuiviDesk CNAS fonctionne de façon 100% autonome et hors-ligne. Tous les enregistrements (collaborateurs, courriers, assignations, wilayas et durées de traitement) sont stockés dans un fichier unique de base de données locale au format SQLite.

📍 Emplacement officiel de vos données sur Windows :
%APPDATA%\suividesk\suividesk.sqlite (accessible via le chemin C:\Users\[Session]\AppData\Roaming\suividesk\).
Ce fichier autonome regroupe la totalité de vos dossiers administratifs et conserve votre historique.
2 Pourquoi et Quand Réaliser une Sauvegarde ?
🛡️ Sécurité & Continuité de Service

Préservez vos dossiers contre toute défaillance matérielle de votre micro-ordinateur, panne système ou manipulation involontaire.

🔄 Changement de Poste ou Formatage

Transférez instantanément l'ensemble de votre bureau de suivi vers un nouveau poste CNAS sans perte d'information.

4 Comment Exporter (Sauvegarder) la Base de Données

L'exportation crée une copie miroir exacte de votre base sans couper votre session de travail. Suivez ces 3 étapes :

Étape 1 Ouvrir la fenêtre « À propos »
Dans la barre de navigation en haut à droite, cliquez sur le bouton « À propos » (icône information).
Figure 2 : Bouton « À propos » dans le menu supérieur droit
Étape 2 Cliquer sur « Sauvegarder la base »
Dans la fenêtre modale officielle, localisez la section « Sauvegarde & Sécurité des Données », puis cliquez sur le bouton bleu principal « Sauvegarder la base ».
Figure 3 : Section Sauvegarde et bouton d'exportation de la base SQLite
Étape 3 Enregistrer le fichier dans un dossier sécurisé
La boîte de dialogue Windows s'ouvre avec un nom horodaté (ex: CNAS_SuiviDesk_Backup_2026-11-16.sqlite). Choisissez le dossier cible (clé USB CNAS, lecteur partagé ou Documents) et validez. Un bandeau vert confirme le succès.

5 Comment Importer (Restaurer) la Base de Données

La fonction de restauration permet de recharger une sauvegarde antérieure afin de retrouver instantanément tous vos dossiers.

Déroulement Les 4 phases de l'importation
  1. Cliquez sur « À propos » en haut à droite de l'écran principal.
  2. Dans le cadre bleu, cliquez sur le bouton « Restaurer » (icône flèche montante).
  3. Le message de confirmation s'affiche : confirmez par « OK ».
  4. Sélectionnez votre fichier .sqlite ou .db puis validez. L'application recharge aussitôt vos données !
Figure 5 : Confirmation de sécurité et mécanisme de sauvegarde de secours automatique
🛡️ Protection Automatique Exclusive :
Avant tout remplacement de la base active, SuiviDesk génère automatiquement une copie de secours nommée suividesk_pre_restore_[horodatage].sqlite. Aucune donnée antérieure ne peut être perdue par accident !
6 Bonnes Pratiques & Recommandations Informatiques CNAS
Critère Recommandation Officielle de Sécurité
Fréquence Réalisez une sauvegarde hebdomadaire (le jeudi en fin de journée) ou après chaque saisie volumineuse.
Support externe Copiez impérativement votre fichier de sauvegarde sur une clé USB de service ou un lecteur réseau CNAS.
Intégrité Ne modifiez jamais manuellement le fichier .sqlite avec un éditeur de texte (Bloc-Notes, Word, etc.).
Mises à jour L'installation des nouvelles versions de SuiviDesk préserve automatiquement vos données sans écrasement.
